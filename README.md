# Acelera Tu Ruta - App

Este proyecto es la página web para una escuela de conducción y tienda de accesorios.

## Estructura del Proyecto

El proyecto ha sido optimizado para ser **portable y libre de dependencias complejas**.

- **`index.html`**: Es el archivo principal y único necesario para que funcione la web. Contiene toda la lógica (React), estilos (Tailwind) y estructura. **Solo necesitas abrir este archivo.**

## Carpetas de Organización

Para mantener el proyecto limpio, se han movido los archivos de configuración y backups a carpetas separadas:

- **`dev-config/`**: Contiene archivos de configuración avanzada (Vite, Tailwind, package.json) y el código fuente desglosado (`src/`). Estos archivos son útiles si en el futuro decides instalar Node.js para desarrollar de forma modular.
- **`backup/`**: Contiene versiones anteriores de `index.html` por seguridad.
- **`services/`**: Scripts o servicios adicionales del proyecto.

## Cómo Usar

Simplemente abre el archivo `index.html` en tu navegador favorito (Chrome, Edge, Firefox). No requiere instalación ni comandos.
